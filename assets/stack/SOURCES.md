# Stack cards

Card layout and terminal/mask symbols: custom for Guijorper.

Technology glyphs: [Simple Icons](https://simpleicons.org/), version 16.31.0, [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Brand names and marks belong to their respective owners. Playwright and Codex use custom symbols, not official brand logos.

Cards are self-contained SVGs with no scripts, external fonts or network dependencies when displayed. Regenerate with `node scripts/build-stack-cards.mjs`; regeneration downloads the pinned icon version.
